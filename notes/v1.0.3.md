# Release Notes v1.0.3

## Correções e melhorias

### Segurança (Webview)

- Corrigida vulnerabilidade de Cross-Site Scripting (XSS) no Webview ao exibir o resultado de comparação.
- O fluxo de renderização foi endurecido para evitar injeção de conteúdo malicioso vindo de mensagens dinâmicas.

### Dependencies e auditoria

- Ajustadas dependencies para mitigar alertas do Dependabot/CodeQL.
- Atualizado fast-uri para versão segura via overrides.
- Atualizado serialize-javascript para versão segura via overrides.
- Ajustada cadeia de dependencies de testes para eliminar alertas low remanescentes de auditoria.
- Resultado final: npm audit sem vulnerabilidades (0 low, 0 moderate, 0 high, 0 critical).

### Compatibilidade de timeout (Node/Browser)

- Corrigida tipagem e uso de syncTimeout no Webview para funcionar de forma consistente em ambiente Node e Browser.
- Ajuste aplicado com tipagem compatível entre runtimes e uso de timers via globalThis.

### Manifesto da extensão (package.json)

- Removido bloco activationEvents redundante, pois a ativação já é inferida automaticamente pelas contribuições de comandos e views do manifesto.
- Essa limpeza remove o alerta de recomendação exibido pelo VS Code sem alterar o comportamento funcional da extensão.

### Testes

- Criada uma nova suite de testes unitários para ampliar a cobertura dos módulos principais da extensão.
- Atualizado o teste de manifesto para refletir o comportamento atual sem activationEvents explícitos.
- Cobertura validada com os testes automatizados: 100% em linhas/statements e 100% em funções.
