# Release Notes v1.1.0

## Novidades

### Comparações grandes sem travar (renderização sob demanda)

- A lista de arquivos alterados agora aparece **instantaneamente** (todos colapsados), mesmo em comparações enormes (ex.: 169 arquivos, dezenas de milhares de linhas).
- O diff de cada arquivo é calculado e renderizado **sob demanda** ao expandir o arquivo, e os arquivos são **pré-carregados em segundo plano** (com limite de concorrência, cedendo tempo à interação do usuário). Assim, ao abrir um arquivo ele normalmente já está pronto — e quando ainda não está, é carregado na hora.
- Isso elimina o congelamento da IDE que ocorria ao montar e sanitizar todo o diff de uma vez.

## Correções e melhorias

### Correção de bug

- O resultado da comparação não é mais descartado ao alternar para outra aba e retornar ao painel:
  - O painel usa `retainContextWhenHidden`, mantendo o DOM do Webview vivo enquanto fica oculto.
  - Ao reexibir, apenas o título é re-localizado; o HTML não é reconstruído, evitando apagar o resultado já renderizado.

### Internacionalização

- Migração para a API oficial `vscode.l10n`, com bundles de tradução em `l10n/` (inglês e português do Brasil) e o campo `l10n` no manifesto, no lugar da solução de i18n própria.

### Dependências

- Removida a dependência de runtime `diff` (e o tipo `@types/diff`). A comparação por linhas e por palavras passou a usar uma implementação própria baseada no algoritmo de Myers, mantendo o mesmo comportamento.
- A extensão continua sem dependências de runtime, reduzindo a superfície de manutenção e segurança.

### Ferramentas e build

- Bundler migrado de **webpack para esbuild** (`esbuild.mjs`; scripts `compile`/`watch`/`package`), com bundle de produção menor e build mais rápido.
- Gerenciador de pacotes migrado de `npm` para `pnpm` (lockfile, campo `packageManager` e overrides em `pnpm-workspace.yaml`); workflow de publicação atualizado para `pnpm`.

### Testes

- Modelo híbrido: **Vitest** para a lógica pura (diff, utils, gitService, diffRenderer) e **`@vscode/test-cli`** para os testes que dependem do host do VS Code (extension, gitComparePanel, sidebarProvider).

### Documentação e metadados

- README em inglês como idioma principal, com versão em português (`README.pt-BR.md`) e alternância de idioma entre os dois.
- Campo `sponsor` no manifesto (botão **Sponsor** no Marketplace) e `.github/FUNDING.yml` com as opções de apoio ao projeto.
