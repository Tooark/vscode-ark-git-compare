# Release Notes v1.0.6

## Correções e melhorias

### Segurança e dependências

- Atualização do `dompurify` de `3.4.7` para `3.4.11`, corrigindo três alertas de segurança reportados pelo Dependabot:
  - Bypass de `SAFE_FOR_TEMPLATES`, em que expressões de template sobreviviam à sanitização dentro de conteúdo `<template>` ao usar modos de saída DOM.
  - Política de Trusted Types que persistia após `clearConfig()` e podia contaminar saídas posteriores com `RETURN_TRUSTED_TYPE`.
  - Poluição permanente de `ALLOWED_ATTR` via `setConfig()`, contornando o clone-guard de hooks (correção incompleta do patch da 3.4.7).
- Atualização do `js-yaml` para eliminar a vulnerabilidade de DoS por complexidade quadrática no tratamento de merge keys (GHSA-h67p-54hq-rp68).
- Auditoria de dependências (`npm audit`) sem vulnerabilidades pendentes.

### CI/CD e publicação

- Workflow de publicação ajustado para empacotar a extensão uma única vez e publicar o mesmo artefato `.vsix` no VS Code Marketplace e no Open VSX, garantindo consistência entre os registries.
- Substituição da instalação global de `@vscode/vsce` e `ovsx` por execução via `npx --yes`, simplificando o pipeline.
- Empacotamento e publicação com `--no-dependencies` para evitar reprocessamento das dependências já instaladas via `npm ci`.
- Tokens de publicação passados via variáveis de ambiente em vez da linha de comando, reduzindo o risco de exposição em logs.
